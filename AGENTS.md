# Guidelines for writing agents
Note that i want clean code so that components are reusable and maintainable. Please follow these guidelines when writing agents:
- Use functional components and hooks where possible.
- Keep components small and focused on a single responsibility.
- Use prop types or TypeScript for type checking.
- Avoid using inline styles; use tailwind instead.
